# 팀 협업 마스터 대시보드

Streamlit 기반의 팀 협업 대시보드입니다. 전사 성과 지표, 통합 팀 캘린더, 담당자별 진척도 비교, 실시간 업무 로그를 하나의 랜딩 페이지에서 확인할 수 있습니다.

## 주요 기능

- `st.metric` 기반 전체 과제 수행률 및 전주 대비 증감 표시
- 이번 주 P1 긴급 과제 완료 현황과 금일 외근/휴무 인력 현황 표시
- 담당자별 색상 구분이 적용된 주간 통합 캘린더와 카테고리 필터
- `st.bar_chart` 기반 담당자별 완료/진행/예정 과제 비교
- 마감일이 지난 미완료 과제가 가장 많은 담당자 병목 하이라이트
- 개인 탭에서 과제 상태 또는 일정을 저장하면 `shared_data.json`에 즉시 반영

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

서버 PC에서 실행하면 터미널에 `Network URL`이 출력됩니다. 이 URL을 팀원들에게 공유하면 모든 접속자가 같은 `shared_data.json` 데이터를 기준으로 대시보드를 함께 사용합니다.

## 데이터 관리

- `shared_data.json`은 팀원, 과제, 일정, 업무 로그를 통합 관리하는 단일 공유 데이터 파일입니다.
- 최초 실행 시 파일이 없으면 `app.py`의 기본 샘플 데이터가 자동으로 생성됩니다.
